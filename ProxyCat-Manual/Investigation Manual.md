Q：出现不正常代理地址，无法正常使用代理

![1](./Investigation%20Manual.assets/1.png)

A：检查 API 地址所提供的代理格式是否正确：接口需逐行返回代理地址（支持 `协议://账号:密码@主机:端口`，不写协议按 `http` 处理，协议只支持 http / https / socks5；格式非法的行会被跳过）；接口返回错误信息（如首行为 `error000x-13`）时会按配置错误处理，不会拼成代理地址使用，需要到接口一侧排查（例如本机 IP 是否需要加白）。



Q：为什么运行 ProxyCat 之后我的IP仍然没有改变？

A：本项目并非全局代理，需要将代理设置指向本地监听端口（默认 1080，HTTP 与 SOCKS5 共用），并且保证代理服务器可用，请逐步排查自己的网络。



Q：为什么端口扫描等情况下无法正常代理？
A：本工具的监听端口同时接受 HTTP 与 SOCKS5 两种代理协议，只转发客户端按这两种协议接入的连接；端口扫描等直接发送原始数据包的任务不经过代理协议握手，无法经本工具转发。
